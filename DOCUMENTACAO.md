Documentação do Projeto - CSS Grid Harry Potter
Sobre o projeto

Este projeto foi feito com HTML e CSS, usando CSS Grid para organizar a página. O tema escolhido foi Harry Potter, com cores escuras, dourado, imagens e fontes relacionadas ao mundo mágico.

Objetivo

O objetivo foi praticar CSS Grid e aprender a organizar melhor as partes de uma página, como colunas, linhas e áreas.

Tecnologias utilizadas
HTML5
CSS3
CSS Grid
Media Queries
Google Fonts
Imagens e ícones
Estrutura do layout

A página foi dividida em:

Header
Menu
Main
Footer

O CSS Grid foi usado para organizar essas áreas.

Responsividade

Foram usadas Media Queries para adaptar o site a diferentes tamanhos de tela, como computadores, tablets e celulares.

Tema visual

O projeto usa cores como preto, dourado, vinho e roxo escuro, além de imagens de fundo, sombras e efeitos nos cards.

Conclusão

Com essa atividade, foi possível aprender como o CSS Grid ajuda a criar páginas mais organizadas, bonitas e responsivas.
